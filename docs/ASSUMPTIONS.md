# Assumptions

## Baseline

- synthetic benchmark year: 2023 hourly calendar
- PV area: 30 m²
- PV efficiency: 18%
- heating base temperature: 18 °C
- building HLC: 120 W/K
- heat-pump COP: 3.0
- timestep: 1 hour

## Interpretation

All building and system parameters are illustrative screening assumptions.

The workflow intentionally separates:

- weather-driven temperature deficit,
- useful thermal heating demand proxy,
- heating electricity demand,
- PV electricity production,
- temporal mismatch.

The model does not claim to represent a particular dwelling, HVAC system or heat pump.
