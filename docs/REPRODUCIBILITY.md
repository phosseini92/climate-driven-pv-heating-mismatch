# Reproducibility

## Deterministic baseline

The synthetic benchmark contains no random noise. Repeated execution with the same code and parameters should generate identical tracked CSV/JSON outputs.

Run:

```bash
python scripts/reproducibility_check.py
```

The script executes the baseline pipeline twice and compares SHA-256 manifests for:

- timeseries.csv
- monthly_summary.csv
- summary.json
- model_config.json

Figures are excluded from byte-identity claims because image metadata and rendering libraries may vary across environments.

## Environment

Install dependencies from `requirements.txt` or the project metadata in `pyproject.toml`.

## Data provenance

Synthetic inputs are generated by `src/climate_pv_heating/synthetic.py`.

Observed data should be fetched with `scripts/fetch_open_meteo.py` or supplied as a CSV with the documented columns.
